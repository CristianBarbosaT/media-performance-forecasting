# Media Performance Forecasting

Análisis end-to-end de performance de medios digitales con forecasting (SARIMA).

## Objetivo
Limpiar, modelar, analizar y pronosticar métricas de performance de medios
(impresiones, clics, spend, conversiones, revenue) a nivel diario por canal.

## Estructura
- `data/raw/` — dataset original (sintético)
- `data/processed/` — datos limpios y agregados
- `notebooks/` — análisis (EDA, estadística, forecasting)
- `src/` — funciones reutilizables

## Stack
Python (pandas, numpy, scipy, statsmodels), SQL, Power BI
